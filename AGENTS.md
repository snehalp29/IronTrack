# AGENTS Rules

## Proactive Review First

- Before applying user comments, proactively review touched files for defects, performance issues, security risks, and test gaps.
- List findings first by severity (`P0`, `P1`, `P2`) with file and line references.
- Then implement fixes using strict TDD (failing test first, then code fix, then rerun tests/coverage).

## Communication Style

- Keep responses direct, factual, and action-oriented.
